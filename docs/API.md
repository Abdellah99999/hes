# API

## Base URL

- Backend : http://localhost:3000/api/v1
- Swagger : http://localhost:3000/api/v1/docs

## Principes

- La version API est `v1`.
- Les endpoints sont exposés par le backend seulement.
- L’API est le contrat entre frontend et backend.
- Tous les changements de statut, permissions et données métier sont validés côté backend.

## Exemple de modules

- auth
- shipments
- parcels
- tracking
- scans
- collections
- transfers
- deliveries
- returns

- invoices
