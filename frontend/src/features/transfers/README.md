# Feature : Transfers (Transferts Inter-Agences & Manifestes de Transport)

Ce module gère le transit et le transport principal entre agences :

- Création de manifestes de transfert groupant plusieurs colis (`TransferManifest`).
- Scans de consolidation et de scellés sécurisés.
- Expédition et réception de manifestes avec contrôle d'intégrité (détection des écarts colis manquants / colis en trop).
- Traçabilité des chauffeurs et véhicules affectés aux trajets inter-agences.
